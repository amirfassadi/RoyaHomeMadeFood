## خرید واقعیِ رابط و پرداخت شبیه‌سازی‌شده

Chrome محلی با پروفایل خالی برای هر کشور، از دامنهٔ واقعی محصول ژامبون را به سبد افزود و فرم واقعی خرید مهمان را با دکمهٔ اطلاعات نمونه طی کرد. فقط GET/HEAD همان دامنه مجاز بودند؛ هیچ درخواست نوشتنی، اتصال بیرونی، ورود مدیر یا خطای JavaScript ثبت نشد. نمونهٔ نرخ به مرورگر تزریق نشد. PayPal برای TR/OTHER غیرفعال و روش‌های خارجی در IR غایب بودند.

منبع جهانی ثبت‌شده currency-api با تاریخ دادهٔ ۲۰۲۶-۱۰-۲۶ و نرخ دریافت‌شدهٔ ۲۰۲۶-۱۰-۲۷ بود؛ dollarSource فاکتورها نمونه نبود. این شاهد یک اجرای موفق است و پایداری طولانی‌مدت منابع را ثابت نمی‌کند. سفارش‌های DEMO فقط در پروفایل‌های جدا نگهداری شدند و آن پروفایل‌ها در پایان بسته شدند.

اجرای مقدماتی harness به‌علت انتخابگر مقدار/دکمه و تبدیل نادرست نویسهٔ بازه/برچسب متوقف شد؛ پس از اصلاح harness، هر هشت مسیر PASS شدند. آن توقف‌ها نقص سایت یا موفقیت آزمون محسوب نشدند.

## مدیریت تخفیف و محدودهٔ ارسال

تست مرورگر `scripts/test-admin-settings-browser.mjs` خود SettingsEditor را روی loopback و با HTTP حافظه‌ای اجرا می‌کند. ساخت/ویرایش، id/version، درصد نامعتبر، تاریخ شمسی و تبدیل تهران، سقف‌های خالی، حفظ پیش‌نویس پس از ۴۰۹ و ۵۰۳، reload، موبایل/دسکتاپ و غیرفعال‌بودن ذخیره در حالت demo موفق شدند. این تست جای ذخیرهٔ فرم روی VPS را نمی‌گیرد.

در `scripts/test-admin-http.ts` آزمون PostgreSQL جدا اضافه شد: ایجاد/ویرایش محدوده و تخفیف اختصاصیِ غیرفعال، خواندن از نشست مستقل، audit، مقادیر صفر/نامحدود، رد نسخهٔ قدیمی/ورودی/کد تکراری/Origin و مهمان، حفظ رکوردهای قبلی و پاک‌کردن fixtureها. اجرای نخست CI به شمارهٔ 40502532581 پس از عبور از PostgreSQL و build، هنگام نصب فونت‌های اضافی مرورگر از مخزن Ubuntu به timeout پنج‌دقیقه‌ای رسید؛ تست‌های بعدی اجرا نشدند و این اجرا موفق کامل نیست. در commit b0d32a9f759be045004c962b30c948a8e599333c، همان Chromium نسخهٔ Playwright بدون نصب دوبارهٔ وابستگی‌های سیستم آماده می‌شود؛ هیچ تستی حذف نشده است. اجرای بعدی [40503886210](https://github.com/amirfassadi/RoyaHomeMadeFood/actions/runs/40503886210) روی همین commit با completed/success پایان یافت: هر ۱۰۷ آزمون عمومی/سروری، ۲۱ تشخیص، ۷ یکپارچهٔ PostgreSQL، مرورگر فرم‌ها و هدر و خرید/نرخ‌ها، HTTP واقعی مدیریت، native HTTPS، پشتیبان/بازیابی جدا، ساخت تولیدی و استاتیک موفق شدند؛ audit صفر آسیب‌پذیری گزارش کرد. پیام‌های ADMIN SETTINGS BROWSER PASS و SETTINGS HTTP PASS در لاگ ثبت شدند. در زمان آماده‌سازی نیز TypeScript، ۱۰۷ تست عمومی/سروری، تست مرورگر تنظیمات و سه تست ابزار نگهداری محلی موفق بودند.

محدوده و تخفیف پنل واقعی‌اند؛ checkout آزمایشی طبق پیام خود سایت همچنان مناطق و کد ROYA10 نمونه دارد. این بررسی ادعای اعمال تنظیمات پنل در DEMO یا فعال‌بودن فروش حقیقی ندارد. رسانه و ذخیرهٔ فرم‌های این دو بخش روی VPS در R15 بازند.

## نگهداری و تحویل

راهنمای [تحویل](FINAL-HANDOVER.md) به release نصب‌شده، سورس کاندید، rollback مخصوص همان نصب و تفاوت بکاپ تنظیمات/دیتابیس اصلاح شد. R25 تا بسته‌شدن موارد تحویل باز است.

ابزار `deploy/inspect-maintenance.py` فقط metadata سرویس/timer، سیاست ثبت‌شدهٔ logrotate و حجم journal را می‌خواند؛ محیط، فرمان‌های سرویس و محتوای لاگ را چاپ نمی‌کند. نیازمند sudo از کاربر amir و release دقیق 22ce667 است. سه تست مرز خروجی آن موفق‌اند. وجود timer یا Result=success به‌تنهایی تأیید backup/restore یا تمدید گواهی نیست. این ابزار هنوز روی VPS اجرا نشده و R24 بسته نمی‌شود.

```bash
bash <<'ROYA_MAINTENANCE'

[ "$(id -un)" = amir ] && [ "$HOME" = /home/amir ] || { echo 'Use amir on the Roya VPS'; exit 1; }

  -o "$roya_work/inspect-maintenance.py" \
  https://raw.githubusercontent.com/amirfassadi/RoyaHomeMadeFood/b97ed698d9f4609a6d6c5c6aaaef99262fdcf4f5/deploy/inspect-maintenance.py
printf '%s  %s\n' 1fb3982ac320f65b24c0ceaaf0c460fc74db75a7cb70ca44b6613ca0824b9236 "$roya_work/inspect-maintenance.py" | sha256sum -c -
```

این فرمان فقط پوشهٔ خصوصی ابزار را داخل Roya setup ایجاد می‌کند و گزارش می‌گیرد. تنظیم زمان‌بندی، پاک‌سازی، build، restart، گواهی، backup/restore و نوشتن دادهٔ کسب‌وکار ندارد. در صورت خطای دانلود/هش/نسخه، پیش از اجرا متوقف می‌شود. برای تست نوشتنی بعدی، بکاپ تازهٔ همین release با بازیابی جدا هنوز لازم است.

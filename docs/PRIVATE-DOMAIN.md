# اتصال دامنه به پیش‌نمایش خصوصی VPS

هدف این مرحله، دسترسی به `royahealthyfood.ir` با HTTPS و محافظ ورود خصوصی است. پرداخت، سفارش واقعی، پیامک و نمایه‌سازی همچنان خاموش می‌مانند. ورود مدیر مستقل از محافظ دسترسی آزمایشی باقی می‌ماند.

## بررسی اولیه

از سورس GitHub با commit و SHA-256 ثابت، این فرمان در ترمینال VPS اجرا می‌شود:

```bash
sudo python3 deploy/inspect-private-domain.py
```

بررسی فقط نسخهٔ نصب‌شده، وضعیت سرویس و راه‌اندازی خودکار، تطبیق پرچم‌های خصوصی، ابزارهای موجود، نام دامنه‌های Nginx، نام zoneها و viewهای BIND، پورت‌ها و منابع آزاد را گزارش می‌کند. محتویات فایل محیط، رمز ادمین، کلید نشست، کلید خصوصی TLS، کلید TSIG و تنظیمات کامل چاپ نمی‌شوند. گزارش بر پایهٔ نسخهٔ نصب‌شدهٔ `4497131e733c07627316685e3b91e7a62af75627` است و در نسخهٔ متفاوت متوقف می‌شود.

اسکریپت هیچ رکورد DNS یا پیکربندی نمی‌نویسد، سرویس را راه‌اندازی مجدد نمی‌کند و دیتابیس را تغییر نمی‌دهد. نام‌سرورها پس از تأیید میزبان DNS تعیین می‌شوند؛ نام‌سرور تازه یا آدرس ساختگی وارد ایرنیک نمی‌شود.

## ترتیب استقرار

1. انتخاب میزبان DNS بر اساس گزارش؛ اگر DNS موجود VPS مناسب بود، فقط zone جدید رویا با حفظ دامنه‌های قبلی آماده و بررسی شود.
2. آماده‌سازی ورودی مخصوص دامنه با محافظ خصوصی؛ تمام صفحات، فایل‌های برنامه و APIها محافظت شوند. مسیر عمومی صدور گواهی فقط فایل challenge را سرو کند.
3. تنظیم نام‌سرورها در ایرنیک و رکوردهای دامنه در میزبان DNS؛ تأیید پاسخ authoritative و عمومی. مقصد برنامه‌ریزی‌شده A برای ریشه به `87.107.54.244` و CNAME برای www به ریشه است.
4. صدور HTTPS، آزمون تمدید و بارگذاری با حفظ گواهی‌ها و وب‌سایت‌های قبلی.
5. ساخت و تنظیم برنامه برای مبدأ HTTPS واقعی؛ تغییر DNS به‌تنهایی URL ورود، کوکی امن و مبدأ درخواست برنامه را تغییر نمی‌دهد. نسخهٔ localhost فعلی مسیر بازگشت باقی بماند تا آزمون دامنه تمام شود.
6. آزمون رد کاربر ناشناس، ورود خصوصی، ورود/خروج مدیر، APIهای مجاز و نامجاز و مسیر مهمان شبیه‌سازی‌شده. دریافت نرخ بازار، با انتقال پول متفاوت است؛ مسیرهای عملیات واقعی باید همچنان STAGING_ONLY بمانند.

نصب اولیه و بررسی فقط‌خواندنی، تأیید پایان این مراحل نیستند. تغییرات Nginx، DNS و نشانی برنامه پس از آماده‌سازی بستهٔ جدا و قابل بازگشت انجام می‌شوند.

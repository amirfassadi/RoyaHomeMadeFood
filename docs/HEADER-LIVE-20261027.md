## آزمون مستقل روی دامنه

مرورگر Chrome با context جدا، بدون ورود، بدون تزریق state و با مسدودبودن تمام درخواست‌های غیر GET/HEAD به دامنه وصل شد. پایان آزمون `2026-10-26T21:17:13.148Z`، برابر ۲۷ اکتبر ساعت ۰۰:۴۷ تهران است. این آزمون به خود VPS از بیرون وصل شد؛ fixture محلی یا API محلی Nginx نیست.

۵۲ مشاهدهٔ واقعی با PASS ثبت شد: خانه، کاتالوگ، محصول، نرخ، درباره، FAQ، تماس، پیگیری، حساب و سبد در FA/EN، در عرض‌های ۱۴۴۰ و ۳۷۵؛ به‌علاوهٔ کاتالوگ/نرخ در عرض‌های ۳۲۰، ۶۴۰ و ۷۶۸ برای هر دو زبان. ناوبری اصلی با کلیک واقعی لینک‌ها، هشت لینک منوی موبایل، انتخاب محصول از ویترین، بازشدن FAQ، بازدید سبد و تغییر زبان با حفظ مسیر بررسی شدند.

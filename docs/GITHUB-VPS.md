# نصب نسخهٔ خصوصی از GitHub

شاخهٔ `vps-private-preview` سورس نسخهٔ یکپارچهٔ آزمایشی VPS را نگه می‌دارد. ثبت کد یا بازشدن PR، مجوز انتشار فروشگاه نیست. `vercel.json` استقرار خودکار این شاخه را غیرفعال می‌کند؛ شاخهٔ اصلی و نسخهٔ فعلی Vercel تغییر نمی‌کنند.

برای هر نصب، آرشیو GitHub با SHA کامل commit دانلود و SHA-256 همان آرشیو پیش از استخراج بررسی می‌شود. از نشانی متغیر `main` یا آخرین نسخه برای اجرای مستقیم اسکریپت استفاده نکنید. فرمان اختصاصی هر نسخه همراه نتیجهٔ آزمون‌ها تحویل داده می‌شود؛ هیچ دانلود یا انتقالی از ویندوز لازم نیست.

پس از استخراج آرشیو، `bash deploy/install-private-from-source.sh` را با کاربر `amir` اجرا کنید. این اسکریپت ۲۱۸ فایل سورس را با manifest بررسی و بستهٔ نصب قبلاً آزموده‌شده را از همان سورس آماده می‌کند. نصب‌کنندهٔ اصلی نیز نسخه و سورس نصب قبلی را بررسی می‌کند. پیش از جابه‌جایی، ساخت تولیدی کامل انجام و نسخهٔ قبلی و تنظیمات خصوصی برای بازگشت حفظ می‌شوند. شکست بررسی پس از جابه‌جایی، بازگشت خودکار دارد.

این بسته از دو مبدأ شناخته‌شدهٔ `db42c9d14deb85dffc22f8459ff9cc18c8fa1be8` و `0a93ac9c6cedfaa26a590c6bdcea2e4062c6f593` به `3b7a85cf8bd17fc7e5bbc128971d4517f15f8f18` ارتقا می‌دهد. نصب‌کننده هش کامل سورس هر مبدأ را مستقل بررسی می‌کند؛ نسخهٔ ناشناخته را نمی‌پذیرد و نصب تکراریِ مقصد را ردوبدل نمی‌کند. پس از نصب، راهنمای `ADMIN-TESTING.md` برای پشتیبان و آزمون ادمین قابل اجراست.

فقط `roya-preview.service` روی `127.0.0.1:3311` به‌روز می‌شود. دیتابیس migration یا seed نمی‌شود؛ پنل واقعی، تنظیمات، سرویس بک‌اند قبلی، Nginx و گواهی‌ها حفظ می‌شوند. پرداخت و سفارش واقعی، پیامک و دسترسی عمومی فعال نمی‌شوند. دسترسی مرورگر همچنان از تونل SSH است. اطلاعات محرمانه در `/etc/roya` روی VPS می‌مانند و داخل GitHub قرار نمی‌گیرند.

پس از نصب موفق، پیام `PRIVATE LIVE RATES FIX READY` و فرمان بازگشت چاپ می‌شود. صفحهٔ نرخ‌ها را با بازخوانی کامل مرورگر باز کنید. تکمیل نصب، جای آزمون مرورگر روی خود VPS را نمی‌گیرد.

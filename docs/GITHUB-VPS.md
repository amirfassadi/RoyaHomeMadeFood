# نصب نسخهٔ خصوصی از GitHub

شاخهٔ `vps-private-preview` سورس نسخهٔ یکپارچهٔ آزمایشی VPS را نگه می‌دارد. ثبت کد یا بازشدن PR، مجوز انتشار فروشگاه نیست. `vercel.json` استقرار خودکار این شاخه را غیرفعال می‌کند؛ شاخهٔ اصلی و نسخهٔ فعلی Vercel تغییر نمی‌کنند.

برای هر نصب، آرشیو GitHub با SHA کامل commit دانلود و SHA-256 همان آرشیو پیش از استخراج بررسی می‌شود. از نشانی متغیر `main` یا آخرین نسخه برای اجرای مستقیم اسکریپت استفاده نکنید. فرمان اختصاصی هر نسخه همراه نتیجهٔ آزمون‌ها تحویل داده می‌شود؛ هیچ دانلود یا انتقالی از ویندوز لازم نیست.

پس از استخراج آرشیو، `bash deploy/install-private-from-source.sh` را با کاربر `amir` اجرا کنید. این اسکریپت ۲۲۱ فایل سورس را با manifest بررسی می‌کند و پیش از نصب، پشتیبان خصوصی دیتابیس و بازیابی آن در دیتابیس جدا را تأیید می‌کند. نصب‌کنندهٔ اصلی نیز نسخه و سورس نصب قبلی را بررسی می‌کند. پیش از جابه‌جایی، ساخت تولیدی کامل انجام و نسخهٔ قبلی و تنظیمات خصوصی برای بازگشت حفظ می‌شوند. شکست بررسی پس از جابه‌جایی، بازگشت خودکار دارد.

این بسته از مبدأ نصب‌شدهٔ `3b7a85cf8bd17fc7e5bbc128971d4517f15f8f18` به نسخهٔ درج‌شده در `deploy/private-preview-manifest.json` ارتقا می‌دهد. نصب‌کننده هش کامل سورس مبدأ را بررسی می‌کند؛ نسخهٔ ناشناخته را نمی‌پذیرد و نصب تکراریِ مقصد را ردوبدل نمی‌کند. پس از نصب، راهنمای `ADMIN-TESTING.md` برای پشتیبان تازه و آزمون `--catalog` قابل اجراست.

نسخهٔ جدید محصولات فعالِ دسته‌های فعال را از دیتابیس ادمین در ویترین نشان می‌دهد. اگر محصول فعالی ندارید، ویترین خالی است؛ محصول ساختگی در دیتابیس ساخته نمی‌شود. سبد این حالت کلید ذخیرهٔ جدا دارد و سبد قدیمی محصولات نمونه را پاک یا وارد نمی‌کند. پیش از بررسی هزینه و ساخت فاکتور، آخرین قیمت، موجودی و ظرفیت دوباره خوانده می‌شوند؛ تغییر مبلغ به تأیید مجدد هزینه نیاز دارد. سفارش آزمایشی همچنان فقط در مرورگر ذخیره می‌شود و موجودی را کم نمی‌کند.

فقط `roya-preview.service` روی `127.0.0.1:3311` به‌روز می‌شود. دیتابیس migration یا seed نمی‌شود؛ پنل واقعی، تنظیمات، سرویس بک‌اند قبلی، Nginx و گواهی‌ها حفظ می‌شوند. پرداخت و سفارش واقعی، پیامک و دسترسی عمومی فعال نمی‌شوند. دسترسی مرورگر همچنان از تونل SSH است. اطلاعات محرمانه در `/etc/roya` روی VPS می‌مانند و داخل GitHub قرار نمی‌گیرند.

پس از نصب موفق، پیام `PRIVATE DATABASE STOREFRONT READY` و فرمان بازگشت چاپ می‌شود. فروشگاه و صفحهٔ نرخ‌ها را با بازخوانی کامل مرورگر باز کنید. تکمیل نصب، جای آزمون مرورگر روی خود VPS را نمی‌گیرد.
